Request mẫu

Tên trường và chuỗi JSON phải dùng dấu ngoặc kép.

{
  "question": "Chứng từ kế toán được hiểu là gì?",
  "reference_date": "2026-10-17",
  "top_k": 5
}

Gọi từ JavaScript

const response = await fetch("/ask", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    question: "Chứng từ kế toán được hiểu là gì?",
    reference_date: "2026-10-17",
    top_k: 5
  })
});
const result = await response.json();

Phản hồi gồm những gì?

answer và citations là câu trả lời và nhãn nguồn. sources có tiêu đề tài liệu, loại nguồn, đoạn trích và URL nếu có.

retrieved_document_ids, retrieved_chunk_ids, confidence, abstain và latency_ms giúp UI hiển thị nguồn, độ tin cậy, trạng thái từ chối và thời gian xử lý.

Nếu Data Pack không đủ căn cứ, API trả abstain: true và thông báo từ chối thay vì tự suy đoán.
